# Day 3 – Your First Agent: What an Agent Is and LangChain

## Topics Learned

### 1. Chatbot vs AI Agent
Learned the difference between a chatbot that generates responses and an AI agent that can make decisions and perform actions using tools to achieve a goal.

### 2. Four Parts of an AI Agent
- Brain – Large Language Model (LLM)
- Instructions – System prompt, rules and guidelines
- Tools – Functions that allow the agent to perform actions
- Memory – Stores conversation history and context

### 3. Agent Loop
Learned how an agent works through the following process:

Think → Act → Observe → Repeat

The agent decides what to do, uses a tool, observes the result and continues until the goal is achieved.

### 4. Three Levels of AI
- Traditional Software – Works using predefined rules.
- Generative AI – Generates content based on prompts.
- Agentic AI – Makes decisions and performs actions using tools.

### 5. When to Use an AI Agent
Learned when to use traditional programming, a single LLM call or an AI agent depending on the problem and its requirements.

### 6. Introduction to LangChain
Learned how LangChain helps build AI applications by connecting language models, prompts, memory and other components.

### 7. LangChain Basics
- ChatPromptTemplate
- MessagesPlaceholder
- StrOutputParser
- Chains using the pipe operator

### 8. Testing an AI Assistant
Learned how to test chatbot responses using test questions, expected outputs and pass/fail results, and improve prompts based on testing.

## Practical Implementation

Built a Sweet Crumbs Home Bakery assistant using LangChain.

The assistant uses a system prompt, conversation history and an LLM to respond to customer questions about bakery products, prices and ordering information.

## Learning Outcome

Learned the basic architecture of an AI agent, how the agent loop works, when to use agents, and how to build and test an AI assistant using LangChain.
