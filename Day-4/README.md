# Day 4 – Tools, Structured Output and Google Sheets

##  Overview
Day 4 of the Drive Ready AI Agents | One Person Company (OPC) training focused on making AI agents more useful by connecting them with tools, handling structured data, and integrating Google Sheets.

In this session, I worked on a bakery-based AI agent called **Sweet Crumbs Home Bakery**, which helps customers with bakery-related queries and order management.

##  Topics Covered
- **Tools in AI Agents** – Allowing AI agents to perform specific actions.
- **Function Calling** – Enabling an LLM to call functions when required.
- **LangChain Tools** – Creating custom tools using the `@tool` decorator.
- **Agent Execution and Traces** – Understanding how an agent selects and executes tools.
- **Structured Output** – Organizing AI responses into a predefined format using Pydantic.
- **Google Sheets Integration** – Connecting the AI agent to Google Sheets.
- **Order Management** – Saving customer order details into a spreadsheet.

##  Technologies Used
- Python
- LangChain
- Groq LLM
- Pydantic
- Google Colab
- Google Sheets
- Gspread

##  Project – Sweet Crumbs Home Bakery AI Agent
The AI agent is designed to assist customers with bakery-related information and order management.

### Features
- Check bakery menu and prices.
- Provide bakery opening hours.
- Collect customer order details.
- Organize orders using structured output.
- Save customer orders to Google Sheets.

##  Workflow
1. The customer interacts with the AI agent.
2. The agent understands the customer's request.
3. The agent selects the appropriate tool.
4. The tool performs the required action.
5. Customer order details are organized into a structured format.
6. Orders are stored in Google Sheets.

##  Learning Outcome
Through Day 4, I learned how AI agents use tools to perform tasks, how structured output helps organize data, and how Google Sheets can be integrated into an AI agent workflow for storing customer orders.
