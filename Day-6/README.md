# Day 6 – LangGraph Chatbot with Tools

## 📌 Overview
Day 6 of the DriveReady AI Agents – One Person Company (OPC) training focused on building a chatbot using LangGraph and integrating external tools to make the chatbot more capable of retrieving information.

In this session, I worked on creating a chatbot that uses tools such as Wikipedia to retrieve information and responds to user queries using an LLM.

## 📚 Topics Covered
- Introduction to LangGraph.
- Building a chatbot using LangGraph.
- Working with tools.
- Integrating Wikipedia and Arxiv tools.
- Binding tools with an LLM.
- Creating a chatbot state using TypedDict.
- Building a graph using StateGraph.
- Using ToolNode and tools_condition.
- Connecting chatbot nodes and tool nodes.
- Compiling and executing the LangGraph workflow.

## 🛠️ Technologies Used
- Python
- Google Colab
- LangGraph
- LangChain
- Groq API
- Wikipedia
- Arxiv
- LangChain Community

## 🤖 Project – LangGraph Chatbot with Tools
The project involves building a chatbot that can interact with users and use external tools to retrieve information when needed.

### Features
- Interact with users through a chatbot.
- Retrieve information using Wikipedia.
- Integrate tools with an LLM.
- Use LangGraph to control the chatbot workflow.
- Process user queries and generate responses.

## 🔄 Workflow
1. Install the required Python libraries.
2. Set up Wikipedia and Arxiv tools.
3. Configure the Groq LLM.
4. Bind tools to the LLM.
5. Define chatbot state using TypedDict.
6. Create chatbot and tool nodes.
7. Connect nodes using graph edges and conditional routing.
8. Compile the graph.
9. Run the chatbot and test queries.

## 🎯 Learning Outcome
Through Day 6, I learned how to build a chatbot using LangGraph, integrate external tools, connect an LLM with tools, and create a graph-based workflow for handling user queries.
